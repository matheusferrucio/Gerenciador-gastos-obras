# GERENCIADOR DE GASTOS DE OBRAS
<p align="center"><img src="http://img.shields.io/static/v1?label=STATUS&message=EM%20DESENVOLVIMENTO&color=GREEN&style=for-the-badge"/></p>

Observando minha rotina eu percebi uma oportunidade de criar uma solução para melhorar a administração de obras do escritório onde trabalho. E foi assim que esse sistema nasceu!

Eu precisava resolver alguns problemas, que são:

- Muito trabalho manual, aumentando probabilidade de erros humanos
- Falta de padronização
- Falta de eficiência na coleta e análise dos dados necessários para mensurar o desenpenho do time
- A falta de uma ferramenta apropriada e específica para nosso uso
- O modelo antigo não era escalável e tinha um ritmo limitado
